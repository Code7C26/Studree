# 📚 Studree

## Descripción

Studree es una carpeta digital hecha para ayudar a los estudiantes a tener sus materias más organizadas.  
La aplicación permite guardar apuntes, archivos y contenido de cada materia en un solo lugar para que sea más fácil acceder a todo.

---

## Problemática

Muchos estudiantes tienen los apuntes y archivos desordenados entre carpetas, WhatsApp, PDFs o distintas aplicaciones.  
Eso hace que se pierda tiempo buscando material o que algunas cosas se terminen perdiendo.

---

## Propuesta de solución

La idea de Studree es que cada usuario pueda organizar sus materias dentro de la aplicación y tener todo más ordenado y accesible.

Con la app se pueden:
- separar materias,
- guardar apuntes,
- subir archivos,
- y mantener el contenido organizado.

---

## Público objetivo

El proyecto está pensado para:
- estudiantes secundarios,
- estudiantes universitarios,
- y personas que hagan cursos.
