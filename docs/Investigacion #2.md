# Investigación sobre estructura visual y navegación - Studree

## Objetivo
Definir cómo se organizarán las pantallas y la navegación principal del proyecto Studree.

---

## Idea principal

Studree será una carpeta digital educativa donde los usuarios podrán organizar:

- Materias
- Apuntes
- Tareas
- Mapas conceptuales
- Archivos

La aplicación buscará ser simple, visual e intuitiva.

---

## Pantallas principales

### 1. Pantalla de inicio
Funciones:
- Mostrar materias recientes
- Acceso rápido a carpetas
- Barra de búsqueda

---

### 2. Vista de materias
Funciones:
- Separar contenido por materias
- Mostrar apuntes y tareas
- Permitir crear nuevos temas

---

### 3. Vista de mapas conceptuales
Funciones:
- Crear nodos conectados
- Organizar ideas visualmente
- Relacionar conceptos

---

### 4. Perfil del usuario
Funciones:
- Configuración básica
- Información del usuario
- Preferencias visuales

---

## Diseño visual

Se propone:
- Interfaz moderna
- Colores oscuros con detalles violetas
- Diseño minimalista
- Navegación simple

---

La estructura propuesta permitirá que Studree funcione como una plataforma educativa moderna, organizada y visualmente intuitiva.
