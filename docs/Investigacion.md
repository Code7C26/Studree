# Investigación de librerías para mapas conceptuales - Studree

## Objetivo
Investigar herramientas para implementar mapas conceptuales y organización visual dentro de Studree.

---

## React Flow

Descripción:
React Flow es una librería para crear diagramas interactivos mediante nodos conectados.

Ventajas:
- Interfaz moderna
- Permite mover nodos
- Muy visual e interactiva
- Ideal para mapas conceptuales

Desventajas:
- Requiere aprender React
- Puede ser compleja al inicio

Link:
https://reactflow.dev/

---

## Mermaid

Descripción:
Mermaid permite crear diagramas usando texto.

Ventajas:
- Fácil de usar
- Liviana
- Buena para diagramas simples

Desventajas:
- Menos interactiva
- Diseño más limitado

Link:
https://mermaid.js.org/

---

## GoJS

Descripción:
GoJS es una librería avanzada para diagramas y gráficos interactivos.

Ventajas:
- Muy profesional
- Muchas funciones
- Personalizable

Desventajas:
- Más difícil de aprender
- Algunas funciones son de pago

Link:
https://gojs.net/

---

## Conclusión

La librería más recomendable para Studree sería React Flow, ya que permite crear mapas conceptuales interactivos y modernos, alineados con la idea principal del proyecto.
