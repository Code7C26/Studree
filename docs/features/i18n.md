# Idiomas (castellano / inglés) — Fase 18

> Estado: 🟡 En desarrollo · Spec: `docs/superpowers/specs/2026-10-28-ingles-design.md` ·
> Plan: `docs/superpowers/plans/2026-10-28-fase-18-ingles.md`.

## Qué hace

Un selector **Castellano / English** en **Perfil** que traduce toda la interfaz al instante.
El idioma se recuerda en el dispositivo (`localStorage`, `studree:ui:lang`) y sobrevive al cerrar
sesión. El Brote responde en el idioma del mensaje del usuario.

## Qué se traduce y qué no

| Se traduce | No se traduce |
|---|---|
| Todo texto visible: JSX, `aria-label`, `title`, `placeholder`, mensajes de error de `services/`, etiquetas en constantes, fechas y orden alfabético | Contenido del usuario (hojas, carreras, materias, notas, tareas, fechas) |
| La landing (`/bienvenida`), que sigue el idioma guardado o el del navegador | `console.*` y mensajes de desarrollo |
| Errores y topes del asistente (por `code` + `reason`) | Identificadores de la base (`aprobada`, `cursar`…) y `<title>`/Open Graph de `index.html` |
