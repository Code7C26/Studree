# Fase 11 — La Carpeta: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que cada materia se vea como una carpeta escolar: todas sus hojas (sin título, con fecha y hora) en un solo scroll sobre papel blanco, con índice de temas, buscador y modo lectura. También se eliminan el canvas de hojas y las tablas viejas.

**Architecture:**
- La migración `0004` convierte los títulos en temas (`# título`), elimina `sheet_links`, `units` y `topics`, y deja `sheets.title` nulo.
- En el cliente, una página `SubjectFolderPage` monta un editor TipTap por hoja, cada uno con su propio autosave (`useSheetAutosave`).
- El índice y los `[[links]]` salen de funciones puras sobre el Markdown.
- El resaltado de búsqueda y de links lo hace una extensión de TipTap con decoraciones.

**Tech Stack:** React 18, Vite 5, JS + JSDoc, Tailwind 3.4, TipTap 3 (`@tiptap/react`, `@tiptap/pm` — peer ya instalada), Supabase.

**Spec:** `docs/superpowers/specs/2026-10-14-carpeta-design.md`

## Global Constraints

- JavaScript + JSDoc, sin TypeScript. Sin dependencias nuevas (`@tiptap/pm` ya está en el lockfile como peer de `@tiptap/react`; solo se declara en `package.json` con la misma versión `3.31.3`).
- Colores solo desde `tailwind.config.js`. Tokens nuevos exactos: `paper #ffffff`, `paper-border #d0d7de`, `ink #1f2328`, `ink-muted #59636e`, `warn #f59e0b`.
- Formato de fecha de hoja: `"Martes 14/10 · 18:30"`; con año si no es el actual: `"Martes 14/10/2025 · 18:30"`.
- Markdown es la fuente de verdad (ADR-011). Los componentes no tocan services ni `localStorage`.
- Migración: `0004`. NO tocar `HomePage.jsx` ni la redirección post-login (son de la fase Inicio, rama `fase-inicio`).
- Contrato con el Inicio: `/materias/:subjectId?hoja=:sheetId` posiciona en esa hoja.
- Cada cambio actualiza los docs y el `CHANGELOG.md`. Commits terminados con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Helpers de prueba: `<SP>` = scratchpad de la sesión; `node <SP>/sql.mjs .env.local <archivo|-e SQL>` corre SQL vía la Management API.

## Review Focus

1. **Hoja nueva que se borra antes de guardarse** (id temporal): el ✕ no debe llamar al servidor y no debe quedar un autosave pendiente que la cree después. Se cubre en la Task 5.
2. **`#` dentro de bloques de código o `#hashtag`** no son temas del índice. Se cubre en el test de `extractHeadings`, Task 2.
3. **Buscar un texto que aparece en varias hojas:** "n de m" cuenta todo y ↑ ↓ cruza de una hoja a otra. Se cubre en el test de `findMatches` (Task 2) y a mano en la Task 9.
4. **`?hoja=` de una hoja que no existe** (borrada): la carpeta abre igual y va a la última hoja. Task 6.
5. **Borrador local de una hoja abierta en otro dispositivo:** sigue la regla de `baseUpdatedAt` de la Fase 0. Se mueve sin cambios a `useSheetAutosave` en la Task 5.
