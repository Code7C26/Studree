# Fase 15 (compartir por link y tarjetas) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que una materia se pueda compartir con un link público de solo lectura y que cada materia tenga un mazo de tarjetas con repaso espaciado.

**Architecture:** Una migración aditiva (`0010`) agrega `shared_links` y `flashcards` con RLS por dueño, más una única función `security definer` (`get_shared_subject`) para la lectura pública, revisada y acotada a un token. La lógica probable sin navegador vive en `src/lib/share/` y `src/lib/flashcards/` (puras, `node --test`); los services hablan con Supabase; los hooks arman el estado; los componentes solo pintan (Mandamiento II).

**Tech Stack:** React 18 + Vite + JavaScript con JSDoc + TailwindCSS + TipTap 3 + Supabase (Postgres, RLS). **Ninguna dependencia nueva.**

**Spec:** `docs/superpowers/specs/2026-11-10-fase-15-compartir-tarjetas-design.md`

## Global Constraints

- **Idioma:** UI, comentarios y docs en castellano rioplatense ("Tenés", "Compartí"), con tildes.
- **JS + JSDoc, NO TypeScript** (ADR-002). Tipar props y retornos (Mandamiento IX).
- **Lógica en `services/` + `hooks/` + `lib/`; presentación en componentes** (Mandamiento II).
- **Carpetas nuevas autorizadas:** `src/lib/share/`, `src/lib/flashcards/`, `src/components/features/share/`, `src/components/features/flashcards/`.
- **Colores/tamaños solo del design system** (Mandamiento VII). Paneles con `.glass`; sobre el papel `ink`/`ink-muted`; íconos SVG de `Icon.jsx`, nunca emojis.
- **Todo texto visible pasa por `t()`** (Fase 18): el trinquete `noSpanishLeft.test.js` lo exige.
- **Ninguna función SQL nueva salvo `get_shared_subject`**, documentada como `security definer` revisada (`set search_path = public`, `revoke all` + `grant execute` a `anon, authenticated`).
- **La migración NO se aplica sin confirmación del estudiante.** Todo lo que corre contra Supabase queda verificado con tests puros y build; el paso de aplicar la 0010 queda marcado `[ESTUDIANTE]`.
- **Tests:** `npm test` + `npx eslint src` + `npm run build` antes de cerrar cada tarea que toca código.
- **Commits:** castellano, prefijo `feat(...)` / `docs:`, sin push.

## Review Focus

1. **El link público no puede filtrar nada más que su materia.** La RPC solo devuelve la materia del token, sus hojas vivas y el nombre de la carrera; nunca ids de usuario ni otras materias. → test SQL y revisión de la función.
2. **Revocar es inmediato.** `revoked_at is not null` ⇒ la RPC devuelve vacío. → step de verificación.
3. **Un usuario no ve tarjetas ajenas.** RLS `auth.uid() = user_id`. → prueba con dos usuarios `[ESTUDIANTE]`.
4. **El repaso no pierde el estado:** acertar/fallar actualiza `box`, `due_at` y `last_reviewed_at` en una sola escritura. → tests de `srs.js` y del service.
5. **La vista pública es solo texto:** se quitan los `adjunto:` y los `[[Tema]]` no navegan. → test de `toPublicMarkdown`.
