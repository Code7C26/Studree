# Fase 18 (Studree en inglés) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un selector Castellano / English en Perfil que traduce toda la interfaz al instante, con el castellano idéntico al de hoy y el Brote contestando en el idioma del mensaje.

**Architecture:** Un módulo puro `src/lib/i18n/` (diccionarios por área + `t` + idioma activo con suscripción) que **no depende de React**, así lo usan por igual componentes, hooks, `lib/` y `services/`. Los componentes se suscriben con el hook `useI18n` (`useSyncExternalStore`), sin proveedor. Se traduce por etapas, un área por tarea, y un test "trinquete" impide que quede castellano suelto en las áreas ya migradas. La Edge Function recibe `uiLang`, manda un `reason` en los topes y el cliente traduce por código.

**Tech Stack:** React 18 + Vite + JavaScript con JSDoc (sin TypeScript) + Tailwind + `node --test`. **Ninguna dependencia nueva de npm.**

**Spec:** `docs/superpowers/specs/2026-10-28-ingles-design.md`

## Global Constraints

- **Idioma del código:** comentarios y docs en castellano rioplatense con tildes; ningún emoji como ícono (ADR-018). **JS + JSDoc, NO TypeScript** (ADR-002). Lógica en `lib/`+`services/`+`hooks/`; presentación en componentes (Mandamiento II).
- **Sin dependencias nuevas de npm** (ni `react-i18next` ni similares).
- **Carpetas nuevas autorizadas por el estudiante** (Mandamiento VI): `src/lib/i18n/` (con subcarpetas `es/` y `en/`). Hook en `src/hooks/useI18n.js`; selector en `src/components/ui/LanguageSelector.jsx`. Ninguna más.
- **El castellano no cambia ni un carácter:** cada texto movido al diccionario `es` es el literal actual, copiado tal cual (incluido el voseo: "Tenés", "Probá").
- **Inglés natural, no literal**, de EE. UU. (`en-US`), voz clara y directa; sin emojis.
- **Qué se traduce:** todo texto que ve el usuario (JSX, `aria-label`, `title`, `placeholder`, mensajes de error devueltos por `services/`, etiquetas en constantes). **No se traduce:** contenido del usuario (hojas, nombres de carreras/materias, notas, tareas, fechas), `console.*` y mensajes de desarrollo, identificadores guardados en la base (`aprobada`, `cursando`, `pendiente`, `cursar`, `rendir`), `index.html` (`<title>`, descripción, Open Graph).
- **Clave de storage:** `STORAGE_KEYS.uiLang = 'studree:ui:lang'`; es una preferencia del dispositivo (no va a Supabase, sin migración).
- **Regla de uso:** los componentes y hooks de React llaman a `useI18n()` (para volver a pintar al cambiar de idioma); `lib/` y `services/` llaman a `t` directo. Un mensaje ya guardado en estado no se retraduce al cambiar de idioma (aceptado).
- **Diccionarios por área:** `src/lib/i18n/es/<area>.js` y `src/lib/i18n/en/<area>.js` (`export default {...}`, objetos anidados, se leen como `t('area.clave.sub')`), reunidos en `es/index.js` y `en/index.js`. Áreas: `common`, `shell`, `auth`, `profile`, `trash`, `home`, `folder`, `editor`, `templates`, `importExport`, `careers`, `careerMap`, `study`, `assistant`, `errors`, `dates`, `landing`. Valores: `string` con `{marcadores}`, o `{one, other}` para plurales (usa `values.count`).
- **Formato de archivos exportados:** las **claves del frontmatter** (`creada:`…) y el formato del `.zip` no cambian de idioma (son formato de archivo y el importador las lee); solo el texto descriptivo sigue el idioma activo.
- **Comandos de cierre de cada tarea:** `npm test`, `npx eslint src supabase`, y `npm run build` al final de las tareas 8, 9, 11 y 12. Correr siempre desde el worktree `.claude/worktrees/fase-18` (Tarea 0).
- **Commits:** en castellano, prefijos `feat(i18n)`, `fix(i18n)`, `docs:`, `test(i18n)`, terminando con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. **No hacer push ni desplegar la función** sin que el estudiante lo confirme (CLAUDE.md, ley 4): esos pasos están marcados **[ESTUDIANTE]**.
- **Docs antes de código** (CLAUDE.md, protocolo 5): el doc `docs/features/i18n.md` se crea en la Tarea 0 y cada tarea lo completa. Cada tarea que toca código suma su línea al borrador de `CHANGELOG.md` 0.19.0.

## Review Focus

1. **Cerrar sesión no puede borrar el idioma.** `clearAllCache()` borra todo lo que empieza con `studree:`; si `studree:ui:lang` cae ahí, el idioma vuelve al del navegador al salir o cambiar de cuenta. → test en Tarea 1.
2. **Una clave que falta o un marcador que no coincide nunca deja la pantalla vacía ni muestra `{name}` crudo.** `t` cae al castellano y, si tampoco está, devuelve la clave; el test de paridad detecta claves y marcadores distintos entre `es` y `en`. → Tarea 1.
3. **El importador sigue leyendo exports en castellano** y un export hecho en inglés conserva `creada:` y las claves del frontmatter. → tests de Tarea 6.
4. **Servidor viejo o código desconocido.** Si la función no está redesplegada (sin `reason`) o llega un `code` nuevo, el cliente muestra el `message` del servidor y no se rompe. → tests de Tarea 8.
5. **Las fechas en castellano no cambian.** Los tests actuales de `sheetDate.test.js` y de `lib/home/dates` pasan **sin tocarlos**, y se agregan los casos en inglés. → Tarea 3.

- `index.js` exporta la instancia real (`t`, `getLang`, `setLang`, `subscribe`, `LANGS`): diccionarios reales, `localStorage` protegido con try/catch, `navigator.language`, y `onChange` que fija `document.documentElement.lang` (con guarda `typeof document`). - `STORAGE_KEYS.uiLang = 'studree:ui:lang'`.

- [ ] **Step 1: Tests `core.test.js`.**
