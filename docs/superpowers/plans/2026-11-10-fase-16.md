# Fase 16 (celular, cámara y lectura sin señal) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que Studree se use cómodo en el celular, que una foto de una hoja se transcriba a una hoja nueva con aprobación del usuario y que la app sea instalable y muestre lo guardado sin señal.

**Architecture:** La transcripción agrega la acción `transcribe` a la Edge Function `assistant` (imagen multimodal de Gemini, cuota propia y migración `0011` para la auditoría). En el cliente, la lógica probable vive en `src/lib/photos/` y `src/lib/assistant/` (puras, `node --test`); un service envía el pedido; hooks y componentes solo orquestan y pintan. La adaptación móvil usa el breakpoint `md` existente y variables CSS del design system. La PWA es un manifest + service worker propio, sin dependencias.

**Tech Stack:** React 18 + Vite + JavaScript con JSDoc + TailwindCSS + TipTap 3 + Supabase (Postgres, RLS, Edge Functions Deno) + Gemini. **Ninguna dependencia nueva.**

**Spec:** `docs/superpowers/specs/2026-11-10-fase-16-celular-camara-design.md`

## Global Constraints

- **Idioma:** UI, comentarios y docs en castellano rioplatense ("Tenés", "Sacá"), con tildes.
- **JS + JSDoc, NO TypeScript** (ADR-002). Tipar props y retornos (Mandamiento IX).
- **Lógica en `services/` + `hooks/` + `lib/`; presentación en componentes** (Mandamiento II).
- **Carpetas nuevas autorizadas:** `src/lib/photos/`, `src/components/features/camera/`.
- **Colores/tamaños solo del design system** (Mandamiento VII). Íconos SVG de `Icon.jsx`, nunca emojis.
- **Todo texto visible pasa por `t()`** (Fase 18): lo exigen `parity.test.js` y `noSpanishLeft.test.js`.
- **La migración NO se aplica sin confirmación del estudiante.** Todo paso contra Supabase/Gemini o redeploy queda marcado `[ESTUDIANTE]`.
- **Tests:** `npm test` + `npx eslint src` + `npm run build` antes de cerrar cada tarea que toca código.
- **Commits:** castellano, prefijo `feat(...)` / `docs:`, sin push.
- **El Brote nunca escribe:** la hoja la crea el cliente solo después de "Crear hoja".
- **La foto no se guarda** en Supabase, Storage ni logs; solo viaja al modelo.

## Review Focus

1. **La imagen no puede romper el servidor ni la cuota.** Validación cerrada de mime/base64/tope y `bodyChars` específico. → tests de `request.js`.
2. **Nada se guarda sin aprobación.** Cancelar en cámara, transcripción o revisión deja la carpeta igual. → tests puros + revisión de componente.
3. **No hay fuga de datos.** La foto no se persiste ni se loguea; el service worker no cachea Supabase. → revisión de `sw.js` y de `transcribe.service.js`.
4. **La app sigue andando sin red.** La carpeta pinta cache y avisa; borrar la cache no pierde datos. → test de `folderSheets` y revisión de `useFolder`.
5. **Móvil no cambia escritorio.** Los estilos nuevos viven detrás de `md:`/`max-md:` y el botón "Foto" solo existe con `useIsMobile()`.
