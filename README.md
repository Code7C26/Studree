# 📚 Studree

## Descripción

Studree es una carpeta digital hecha para ayudar a los estudiantes a tener sus materias más organizadas.

La aplicación permite guardar apuntes, archivos y contenido de cada materia en un solo lugar para que sea más fácil acceder a todo y mantener una mejor organización.

---

## Problemática

Muchos estudiantes tienen sus apuntes y archivos desordenados entre carpetas, WhatsApp, PDFs o distintas aplicaciones.

Esto provoca pérdida de tiempo buscando información y aumenta la posibilidad de perder material importante.

---

## Propuesta de solución

La idea de Studree es que cada usuario pueda organizar sus materias dentro de una plataforma digital y tener todo más ordenado y accesible.

Con la aplicación se busca poder:

- separar materias,
- guardar apuntes,
- organizar archivos,
- y mantener todo el contenido académico en un solo lugar.

---

## Público objetivo

El proyecto está pensado para:

- estudiantes secundarios,
- estudiantes universitarios,
- y personas que realicen cursos o capacitaciones.

## Cómo usar Studree

1. Descargar o clonar el repositorio de Studree.
2. Abrir la carpeta del proyecto utilizando Visual Studio Code.
3. Ejecutar la aplicación desde los archivos del proyecto para visualizar la interfaz.
4. Navegar por la plataforma y utilizar las secciones destinadas a la organización de materias y contenido académico.
